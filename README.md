# ZX48K for RC2014<sup>TM</sup>

## Introduction 

While working on [ZX48-Essentials](https://github.com/tomekszafranski/ZX48essentials) project I thought it would be nice to have a system that could be easily extended step by step, starting from CPU and adding next elements to get a fully loaded computer in the end. I came up with the idea of self-made modular Z80 system. It utilized 40-pin goldpin connector on a stripboard, modules were built using universal PCBs cut to size and components were connected with wires and jumpers. It worked for some time but since only one poor contact is enough to crash, after a while it became difficult to enjoy.

![thumbnail_IMG_8504](https://github.com/user-attachments/assets/71b20718-c213-47b7-b03b-fcb64e4c0bb7)
![thumbnail_IMG_8508_2](https://github.com/user-attachments/assets/ff2cee50-6fe0-4505-aebd-a353caf3a4de)

Soon I found out (RTFM + Internet!) that such a solution already exists – wonderful [RC2014<sup>TM</sup>]( https://rc2014.co.uk/) system created by Spencer Owen – standard that I liked very much at first sight. So having my version of ZX Spectrum ready, designing a version for RC2014<sup>TM</sup> seemed natural thing to do. The idea was to use components already developed for RC2014<sup>TM</sup> system that you might already have: CPU, RAM, ROM and add Spectrum specific part (module) only. As in ZX48-Essentials project, convenient vRetro Design [vLA82S+](https://www.vretrodesign.com/products/vla82s-spectrum-ula-replacement-with-rgb-interface-and-ay-emulator-without-interface) ULA replacement outputting RGB signal is used. To have Spectrum's functionality on top of RC2014<sup>TM</sup> we also need to add video memory used by ULA and EAR/MIC/keyboard section. 

Note: To fully understand following description/discussion, working knowledge of ZX Spectrum design would be useful, but don't worry if you're not an expert - anyone can easily follow the logic and instructions below.

## Step One: Sinclair’s logo

I've designed **ZX Spectrum 48K essentials for RC2014<sup>TM</sup>** module (it will be further referred to it as "Speccy module"). All components follow original ZX Spectrum Issue 3B design (have same [references and values](https://spectrumforeveryone.com/wp-content/uploads/2017/08/ZXSpectrumIssue3b-Schematics.gif)) and the approach to utilizing static Lower RAM memory (in place of painful DRAM) is the same as in modern [memory replacement boards](https://www.retroleum.co.uk/spectrum-repairs-mods). Module design follows RC2014<sup>TM</sup> standard (see [About RC2014 and RCBus standards] discussion for more info).

<img width="902" height="815" alt="Zrzut ekranu 2025-07-15 210149" src="https://github.com/user-attachments/assets/29c3cf36-874e-42fb-9131-5367b919f58f" />

To get Spectrum system running you need (apart from above Speccy module): 
* RC2014 compatible backplane with 4-6 slots (depends on which version you decide to build - read on for more information).
* Z80 CPU module without clock and ideally without reset circuit but with pullup resistors for NMI, WAIT and BUSRQ lines (however they might be also connected directly to +5V). It is also OK to have INT line pulled-up, however in Spectrum it is not. CLK and RESET signals will be supplied by Speccy module. 
* Module with 32KB of RAM at address 8000h with logic to select/read/write it (based on A15, MREQ, RD, WR lines).
* Module with 16KB of ZX Spectrum ROM at 0000h with/or without logic to select/read it (based on A14, A15, MREQ, RD lines). Selecting ROMCS signal can be also generated by Speccy module on Pin 38 (see discussion in Step Three). Program your EEPROM with proper [ROM content](https://speccy4ever.speccy.org/_SIN.htm). 

As you can see in the picture above, Speccy module has couple of jumpers but you can leave them open for now if only your ROM module has select mechanism but most of ready modules have it. See [User defined pins and jumper configuration] for detailed description.

If you install those three modules together with Speccy module on the backplane you should be able to see heartwarming “© 1982 Sinclair Research Ltd” welcome message. Below you can see Speccy module being used with CPU and RAM from RC2014<sup>TM</sup> [Classic II Kit](https://rc2014.co.uk/full-kits/rc2014-classic-ii/). Classic’s ROM module was replaced with [PagedROM](https://rc2014.co.uk/modules/pageable-rom/) module since Classic's original ROM is 8KB only.

![thumbnail_IMG_0587a](https://github.com/user-attachments/assets/1547917c-70af-4c33-a095-a6aa7054ddc5)

Above assumes that you have one of the RC2014<sup>TM</sup> kits or you are a fan of the standard and have different modules lying around. If not, you can use dedicated **ZX Spectrum 48K CPU/ROM/RAM** module to get you going. You should be able to see Spectrum's welcome message using these two modules and the backplane only. As you can see - to be future proof - module is equipped with RC2014<sup>TM</sup> Enhanced bus (partial second row of pins - more on this in Step Three). Double angled goldpins must be used in the middle section. Set jumper to "Int.ROMCS" (which means that module will generate ROMCS signal itself and not rely on Speccy module").

## Step Two: Hello World!

To write a program in BASIC that displays standard “Hello World!” message you need a keyboard. Speccy module has IDC16 connector for it. I haven't found any standard here so I followed reasonable pin assignment described in [ZX81 Keyboard Adventure](https://www.zx81keyboardadventure.com/p/zx-key-keyboard-guide-book.html). 
You can use original ZX Spectrum or ZX Spectrum+ keyboard, ZX81 keyboard or keyboards designed for Harlequin – one with tactile switches or one with mechanical switches using **Keyboard Adapter** below. Of course you need IDC16 ribbon cable as well. Here you can find details about [Keyboard Adapter].

## Step Three: World of Spectrum

At this stage you should be able to load a game from tape and play using the keyboard. However to get full modern Spectrum experience you probably dream about connecting some storage solution e.g. microSD card interface and/or using joystick interface. In order to do this you need working ZX Spectrum's edge connector. This is the place where things get a bit complicated because:

* ZX Spectrum exposes more signals on edge connector that we have available on Standard RC2014<sup>TM</sup> bus so we will have to use Enhanced bus (more pins) - it would affect mainly CPU module that is reponsible for generating those signals
* to use real world extension modules we need a kind of module/PCB/adapter with edge connector itself, the module will utilitize those additional signals
* to connect external peripherials, ability to control /ROMCS signal it needed, so that external device can take over by disabling ZX Specturm's ROM (this the reason why standard ROM modules will not work without modfifications).
  
As you can probably imagine both Speccy modules and CPU/ROM/RAM module are designed to overcome last two points. The only requirements would be to have backplane with enhanced bus and actual edge connector. Why not have it on a backplane itself? Below you can see **Backplane for RC2014<sup>TM</sup> with ZX Spectrum edge connector** :-)

<img width="699" height="1075" alt="Zrzut ekranu 2025-07-15 122157" src="https://github.com/user-attachments/assets/de219821-3f76-419f-a37f-15b84cf7b71a" />



**ZX Spectrum Edge connector for RC2014<sup>TM</sup>** board was designed. The only problem is that edge connector requires more signals then are present on RC2014 Standard bus. To get it running you need to be using RC2014 backplane with Enhanced Bus like [Backplane Pro](https://z80kits.com/shop/backplane-pro/). Its most common middle section - pins 17-26 - carries additional CPU signals (/NMI among them). 

![edge](https://github.com/user-attachments/assets/d412ea3d-8c5e-4902-bae1-70fe9a79de77)

Above edge connector module should be used with Enhanced RCBus backplane (enhanced signals are transferred through backplane). If you have only standard backplane you can still transfer additional signals using wires. You should use upgraded CPU module below that exposes those signals and connect wires from it to edge connector module (install additional 8 pins vertically).

## Remarks

### General
* As in original Spectrum, do not connect/reconnect modules while powered. This is always consider a good practice.
* The only issue I had while assembling above modules was cleaning them properly. It turns out that while soldering, residues of flux remains on goldpin connector and seize proper contact. Clean them carefully with IPA.

### About RC2014 and RCBus standards

If we talk about the standard we mean two things: signals on a bus and0 dimensions of the elements. Signals are not negotiable, the only point of freedom are couple of user defined pins (pin 35+). Read about it [her](https://smallcomputercentral.com/rc2014-bus/specification-rc2014-bus/). But if you talk about the dimensions there are to options: original specification proposed by Spancer Owen and alternative proposed by RCBus 2014. I like shape of original boards however their dimensions are weired and they are squezzed below 100mm in length (it is well known problem that some PCB manufactures PCB production cost increses significantly if you exceed this limit). On the other hand I like logical dimensions of RCBus 2014. So my boards are mixed. but do not worry all modules will fit any backplane the only real problem is with mounting hole.

### User defined pins and jumper configuration
In RC2014<sup>TM</sup>/RCBus 2014 standard, pins 35-40 are user defined.
In Speccy board:
* Pins 35 and 36 are not used because they are commony used as TX/RX by communication modules
* Pin 37 is external sound input, that can be routed to miniDIN connector
* Pin 38 is /ROMCS generated by ULA and is needed if your ROM module does not have it or you plan to use edge connector
* Pin 39 are 40 - these are CLOCK and IORQ signals on ULA side, you need them if you plan to use edge connector
  
Speccy module has four jumpers. First one located on the left under ULA and three more located on the right side of the ULA. The first one specifies source of sound. You can choose onboard vLA82S+ (left) which has read only AY-8-8912 interface or external input on pin 37 (right).
