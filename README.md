# ZX48onRC2014

## Introduction 

While working on [ZX48essentials](https://github.com/tomekszafranski/ZX48essentials) project I wanted to have the ability to gradually extend the system, starting from CPU and adding next elements to get a fully working computer in the end. I came up with the idea of self-made modular Z80 system. It utilized 40-pin gold pin connector on a breadboard, modules were built using universal PCBs and components were connected with wires. It worked for some time but since only one poor contact is enough to crash, after a while it became difficult to enjoy.

![thumbnail_IMG_8508_2](https://github.com/user-attachments/assets/ff2cee50-6fe0-4505-aebd-a353caf3a4de)


Then I found out (RTFM+Internet!) that such a solution already exists! – wonderful [RC2014<sup>TM</sup>]( https://rc2014.co.uk/) system developed by Spencer Owen – standard that I liked very much at first sight. So having my version of ZX Spectrum ready, designing version for RC2014<sup>TM</sup> seemed an obvious thing to do. The initial idea was to use components developed for RC2014<sup>TM</sup> that you might already have: CPU, RAM, ROM and add Spectrum specific part (module) only. As in ZX48essentials, convenient vRetro Design [vLA82S+](https://www.vretrodesign.com/products/vla82s-spectrum-ula-replacement-with-rgb-interface-and-ay-emulator-without-interface) ULA replacement outputing RGB signal is used. To have Spectrum's funtionality we need to add video memory used by ULA and EAR/MIC/keyboard sections.  

OK, so let’s build it!

## Step One: Sinclair’s logo

I've designed **ZX Spectrum 48K essentials for RC2014<sup>TM</sup>** module (I will further refer to it as "Speccy module"). All components follow original ZX Spectrum Issue 3B design (have same references and values) and the approach to utilizing static Lower RAM memory is the same as in modern memory replacement boards. Module design follows RC2014<sup>TM</sup> standard (see discussion [About RC2014 and RCBus standards] for more).

![zx_on_rc2014](https://github.com/user-attachments/assets/9cb38b72-2394-47b3-b192-82742dc48f23)

Here is what you need apart from Speccy module to get it running: 
* Backplane for RC2014<sup>TM</sup> system with 4-6 slots (depends on which version you decide to build - read on for more information).
* Z80 CPU module without clock and ideally without reset circuit but with pullup resistors for NMI, WAIT and BUSRQ lines (however they might be also connected directly to +5V). It is also OK to have INT line pulled-up, however in Spectrum it is not. CLK and RESET signals will be supplied by Speccy module. 
* Module with 32KB of RAM at address 8000h with logic to select it (based on A15, MREQ, RD, WR lines).
* Module with 16KB of ZX Spectrum ROM at 0000h with/or without logic to select it (based on A14, A15, MREQ, RD lines). Selecting ROMCS signal can be also generated by Speccy module on Pin 38 (see discussion in Step Three). Remember to program your EEPROM with proper [ROM content](https://speccy4ever.speccy.org/_SIN.htm). 

Speccy module has some jumpers but you can leave them open for now if only your ROM module has select mechanism. See later [Remarks – Speccy module's jumpers] for description.

If you install those three modules together with Speccy module on the backplane you should be able to see heartwarming “© 1982 Sinclair Research Ltd.” welcome message. Below you can see Speccy module being used with CPU and RAM from RC2014<sup>TM</sup> [Classic II Kit](https://rc2014.co.uk/full-kits/rc2014-classic-ii/). Classic’s ROM module was replaced with PagedROM module since Classic's original ROM is 8KB only (howerver it can be modified to work - see [Remarks – Using Classic Kit ROM]).

[photo-system on RC2014 with message]

Above assumes that you have one of the RC2014<sup>TM</sup> kits or you are a fan of the standard and have different modules lying around. If not, you can use dedicated **CPU/ROM/RAM module** to get you going. You should be able to see Spectrum's welcome message using these two modules only. Module is equiped with RC2014<sup>TM</sup> bus - more on this in Step Three.

## Step Two: Hello World!

To write a program in BASIC that displays standard “Hello World!” message you need a keyboard. Speccy module has IDC16 connector for it. I don't know about any standard here so I followed pin assignment described in [ZX81 Keybord Adventure](https://www.zx81keyboardadventure.com/p/zx-key-keyboard-guide-book.html). 
You can use original ZX Spectrum or ZX Spectrum+ keyboard, ZX81 keyboard or keyboards designed for Harlequin – one with tactile switches or one with mechanical switches using **Keyboard adpater** below. Of course you need IDC16 cable as well.

## Back to Step One?

At the very beginning I said that design of Speccy module is based on ZX48essentials. This project utilizes vLA82S+ ULA replacement and its idea was to build a clone (same components as in original ZX Spectrum 48K). However one can argue that this is unnecessary complication and impractical one for sure. There are projects out there that utilize FPGA which can be progammed to replace ULA with surronding logic. If you are one of these people please see **ZX Spectrum 48K add-on for RC2014<sup>TM</sup>** module below. It has the functionality of Speccy module but is based on Altera EPM7128 FPGA and core used in [ZX 48 Spider](https://github.com/konkotgit/ZX-48-Spider) project. The rest of the story is the same.

## Step Three: World of Spectrum

At this stage you should be able to load a game from tape and play using the keyboard. However to get full modern Spectrum experience you probably dream about connecting microSD card interface. In order to do this you need working ZX Spectrum edge connector.

**ZX Spectrum edge connector module** for RC2014<sup>TM</sup> system was designed. The only problem is that it requires more signals then are present on RC2014 Standard bus. To get it running you need to be using RC2014 Enhanced Bus (at least most common, middle section - Pins……) that has additional CPU signals from which the NMI would be most important. 
Edge connector module should be used with Enhanced RCBus backplane (enhanced signals are transferred through backplane) or with standard bus backplane – enhanced signals are transferred by cables from CPU board to edge connector module. 

![edge](https://github.com/user-attachments/assets/d412ea3d-8c5e-4902-bae1-70fe9a79de77)

To summarize, you have couple of options:
* Use enhanced bus backplane and CPU board that has enhanced bus connector and add edge connector module. If you need such CPU board see repository. Alternatively you can use CPU/ROM/RAM board mentioned earlier.
* Use standard bus backplane and CPU board that has enhanced signals available and connect them to edge connector module by wires. If you need such CPU board see repository.
* You can also use special backplane for RC2014 that has ZX Spectrum edge connector built in :-) You need CPU with enhanced connector.

## Step Four: Get it all!

To get full ZX Spectrum experience, depending on you setup:
* If you use Speccy module with vLA82S+ you have sound chip onboard. You might only need joystick interface.
* If you use Speeccy module with vLA82S+and with edge conector with divMMC interface there is a chance you have joystick interface, no need no more.
* If you use Speccy module with Altera FPGA you need sound card and a joystick interface.
* If you use Speccy module with Altera FPGA and divMMC interface connected to edge connector you might have joystick but you still need sound card.

Whatever you situation is you can find joystick interface, AY Sound interface or both modules available.

## Remarks

### General
* As in original Spectrum, do not connect/reconnect modules while powered. This is always consider a good practice.
* The only issue I had while assembling above modules was cleaning them properly. It turned out that while soldering, residues of flux can remain on gold pin connector and there is no proper contact. Clean them carefully with IPA.

### About RC2014 and RCBus standards

All modules design

### Jumper configuration

Speccy module has four jumpers. One located on the left under ULA and three mode located on the right side of the ULA.

### Using Classic's ROM

Classic's kit ROM is 8KB only. It utilizes xxxx chip which is much bigger but on board logic is set up to use 8KB (size of original BASIC).
