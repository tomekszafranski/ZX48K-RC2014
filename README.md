# ZX48K for RC2014<sup>TM</sup>

## Introduction 

While working on [ZX48-Essentials](https://github.com/tomekszafranski/ZX48essentials) project I thought it would be nice to have a system that could be easily extended step by step, starting from CPU and adding next elements to get a fully loaded computer in the end. I came up with the idea of self made modular Z80 system. It utilized 40-pin goldpin connectors on a stripboard, modules were built using universal PCBs cut to size and components were connected by wires and jumpers. It worked quite well for some time but since only one poor contact is enough to crash, after a while it became difficult to enjoy.

![thumbnail_IMG_8508_2](https://github.com/user-attachments/assets/ff2cee50-6fe0-4505-aebd-a353caf3a4de)

Soon I found out (RTFM + Internet!) that such a solution already exists – wonderful [RC2014<sup>TM</sup>]( https://rc2014.co.uk/) system created by Spencer Owen – standard that I liked very much at first sight. So having my version of ZX Spectrum ready, designing a version for RC2014<sup>TM</sup> seemed natural thing to do. The idea was to use components already developed for RC2014<sup>TM</sup> system that you might already have: CPU, RAM, ROM and add Spectrum specific part (module) only. As in [ZX48-Essentials](https://github.com/tomekszafranski/ZX48essentials) project, convenient vRetro Design [vLA82S+](https://www.vretrodesign.com/products/vla82s-spectrum-ula-replacement-with-rgb-interface-and-ay-emulator-without-interface) ULA replacement outputting RGB signal was used. To have Spectrum's functionality we also need video memory used by ULA and EAR/MIC/keyboard section as these are controlled by ULA. 

Note: To fully understand following description/discussion, a bit of working knowledge of ZX Spectrum design would be useful, but don't worry if you're not an expert - anyone can easily follow the logic and instructions below.

## Step One: Sinclair’s logo

First step was design of **ZX Spectrum 48K essentials for RC2014<sup>TM</sup>** module (further referred as "Speccy module"). All components follow original design of ZX Spectrum 48K Issue 3B (have same [references and values](https://spectrumforeveryone.com/wp-content/uploads/2017/08/ZXSpectrumIssue3b-Schematics.gif)) and the approach to utilizing static Lower RAM memory (in place of painful DRAM) is the same as in modern memory replacement boards. Module design follows RC2014<sup>TM</sup> standard - see [About RC2014 and RCBus standards](#about-rc2014-and-rcbus-standards) section for discussion.

<img width="1273" height="1124" alt="Zrzut ekranu 2026-10-08 143020" src="https://github.com/user-attachments/assets/7b51bf11-9272-4c4a-a409-142943479bc9" />

To get such a Spectrum system running you need (apart from Speccy module): 
* RC2014 compatible backplane with 4-6 slots (depends on which version you decide to build - read on for more information).
* Z80 CPU module without clock and ideally without reset circuit but with pullup resistors for /NMI, /WAIT and /BUSRQ lines (however they might be also connected directly to +5V). It is also OK to have INT line pulled-up, however in original Spectrum design it is not. CLK and /RESET signals will be supplied by Speccy module. 
* Module with 32KB of RAM at address 8000h with logic to select/read/write it (based on A15, /MREQ, /RD, /WR lines).
* Module with 16KB of ROM at 0000h with/or without logic to select it (based on A14, A15, /MREQ, /RD lines). Program your EEPROM with [ROM content](https://speccy4ever.speccy.org/_SIN.htm) for ZX Spectrum 48K. 

As you can see in the picture above, Speccy module has couple of jumpers but you can leave them open for now if only your ROM module has its own select mechanism (most of ready modules do). If not, use /ROMCS signal that is generated by Speccy module on bus pin 38 (and close first of three jumpers). See [User defined pins and jumpers](#user-defined-pins-and-jumpers) section for description.

If you install those three modules together with Speccy module on the backplane you should be able to see heartwarming “© 1982 Sinclair Research Ltd” welcome message. Below you can see Speccy module being used with CPU and RAM from RC2014<sup>TM</sup> [Classic II Kit](https://rc2014.co.uk/full-kits/rc2014-classic-ii/). Classic’s ROM module was replaced with [PagedROM](https://rc2014.co.uk/modules/pageable-rom/) module since Classic's original ROM is 8KB only.

![thumbnail_IMG_0587a](https://github.com/user-attachments/assets/1547917c-70af-4c33-a095-a6aa7054ddc5)

Above assumes that you have one of the RC2014<sup>TM</sup> kits or you are a fan of the standard and have different modules lying around. If not, you can use dedicated **ZX Spectrum 48K CPU/ROM/RAM** module to get you going. You should be able to see Spectrum's welcome message using these two modules and the backplane only. As you can see, module is equipped with RC2014 Enhanced bus (partial second row of pins - more on this in Step Three). Double angled goldpins must be used in the middle section. Set jumper to "int.ROMCS" which means that module will generate /ROMCS signal itself and not rely on Speccy module".

## Step Two: Hello World!

So you have your version of ZX Spectrum running, but to write BASIC program that displays immortal “Hello World!”, you need a keyboard. Speccy module has dedicated IDC16 connector for it. I haven't found any standard for it so I followed reasonable pin assignment described in [ZX81 Keyboard Adventure](https://www.zx81keyboardadventure.com/p/zx-key-keyboard-guide-book.html). 
You can use original ZX Spectrum or ZX Spectrum+ keyboard, ZX81 keyboard or keyboards designed for Harlequin using this **Keyboard Adapter** and IDC16 ribbon cable. Details can be found in [Keyboard Adapter](#keyboard-adapter) section.

## Back to Step One?

At the very beginning it was said that design of Speccy module is based on [ZX48-Essentials](https://github.com/tomekszafranski/ZX48essentials). This project utilizes vLA82S+ ULA replacement and its idea was to build a clone (same components as in original ZX Spectrum 48K). ## Step Three: World of Spectrum

At this stage you should be able to load a game from tape and play using the keyboard. However to get modern Spectrum experience you probably dream of connecting a storage solution e.g. microSD card interface and/or joystick/sound interface. In order to do this you need working ZX Spectrum's edge connector. This is the place wnere things get a bit complicated because:

* To use real world extension modules we need to add physical edge connector
* ZX Spectrum exposes more signals on its edge connector that we are available on RC2014 Standard bus, so we will have to route additional wires (from CPU to edge connector) or - in more elegant - use Enhanced bus instead (more pins/signals). This would affect CPU module that is responsible for supplying those signals and potentially also the backplane (if we decide to use Enhanced bus to transmit them)
* Also, using more intelligent external peripherals, require control of /ROMCS signal, so that ZX Specturm's ROM can be disabled.

To setup such a system using RC2014 components (assuming Enhanced bus is used) you need:

* **ZX Spectrum Edge connector for RC2014<sup>TM</sup>** module, shown below. Additional pins carry more CPU signals (e.g. /NMI). 
* Backplane that support Enhanced bus - e.g. [Backplane Pro](https://rc2014.co.uk/backplanes/backplane-pro/)
* CPU module that exposes addtional signals - e.g. [Z80 CPU v2.1](https://rc2014.co.uk/modules/z80-cpu-v2-1/)
* ROM module like [Pageable ROM](https://rc2014.co.uk/modules/pageable-rom/) modified to be selected by external signal on bus pin 38

<img width="1189" height="394" alt="Zrzut ekranu 2026-10-08 145050" src="https://github.com/user-attachments/assets/e13f9275-a5ff-458a-b87b-2e5855136425" />

Alternatively, if you don't want to invest in new backplane and/or modules you may still use Standard backplane you have. ZX Spectrum Edge connector module can be used either with Enhanced bus backplane (additional signals are trasmitted using backplane - use goldpin socket facing downwards for new signals) or Standard bus backplane (additional signals are transmitted using dupont wires - use goldpin headers facing upwards for new signals). In second case you also need simple **CPU board** below that exposes additional signals (reset circuit is optional and not used in our case).

## Remarks

### General
* As in original ZX Spectrum, do not connect/reconnect modules while powered. This is always consider a good practice.
* All RC2014 modules are powered by standard power supply meaning that center pin is positive which is different from original ZX Spectrum PSU!
* No additional voltages are supplied and passed to edge connector, so some peripherals (like ZX Interface I) will now work
* The only issue I came accoss assembling above modules was cleaning them properly. It turned out that while soldering, residues of flux may remain on goldpin connector and seize proper contact. Clean it with IPA.

### About RC2014 and RCBus standards

If we talk about standards, there are two things to consider: signals on a bus and dimensions/shape of the module. There are two specification available: original RC2014 specification proposed by Spencer Owen and wider alternative RCBus proposed by Stephen C Cousins (also big fan :-).  Both specifications agree on signals and that is not negotiable, the only point of freedom you have is use of user defined pins (pin 35-40). Detailed description can be found on [Small Computer Central](https://smallcomputercentral.com/rc2014-bus/specification-rc2014-bus/). Be aware that some RC2014 modules have only 39 pins due to limited size.

Dimensions of the modules (however still a part of specification) are more of aesthetics concern. I like shape of original boards (punched card) however their dimensions are weired - size of base module is 99.1mm x 49.9mm with 39 pins as it is squeezed below 100mm in length (it is well known problem with some PCB manufactures - PCB production cost increases significantly if you exceed this limit). Other suggested sizes (height) are: 25.0mm, 31.8mm, 75mm and 100mm. On the other hand, I like logical dimensions of RCBus - width of the module is 4", and the heights are: 1", 1.5", 2", 4" and it is 40 pin wide). So my designs are mixed, I keep original punch card shape but use standardized size in inches. If you are concerned about compatibility with others modules - they will always work if pins assignment is correct. Size is aesthetics concern. The only real problem is location of the hole used for connection between modules - it will really fit :-(

### User defined pins and jumpers
Speccy module has four jumpers. First one located on the left under ULA and three more located on the right side of the ULA. 
In RC2014<sup>TM</sup>/RCBus 2014 standard, pins 35-40 are user defined. In Speccy board:

| **RCbus user defined pin** | **Configuration details** |
| :------ | :------ |
| **Pin 35,36** |  not used by Speccy modules because they are commonly used as TX/RX by communication modules |
| **Pin 37** Audio | For vLA82S Speccy module this selects source of the sound routed to miniDIN AV connector of Speccy module: internal VLA82S which is equipped with sound generator (west position) or external signal delivered on Pin 37 (east position) |
| **Pin 38** /ROMCS | generated by ULA and is needed if your ROM module does not have it or you plan to use edge connector (external modules might want to use it) |
| **Pin 39** CLOCK | these are CLOCK and IORQ signals on ULA side, you need them if you plan to use edge connector |
| **Pin 40** IORQ | these are CLOCK and IORQ signals on ULA side, you need them if you plan to use edge connector |

### Programming Altera MAX7000

CPLD version of Speccy module uses Altera MAX EPM7128SLI84-10 chip available (at the moment of writing, relatively easy) from eBay/Aliexpress. Needed socket is PLCC84. To program with included *.pof file you need USB-Blaster programming device, also available from eBay/Aliexpress. Programming software is Quartus II 13.1 Programmer available from [Altera](https://www.altera.com/downloads/fpga-development-tools/quartus-ii-web-edition-design-software-version-13-1-windows). Chips from MAX7000S use In-System Programming via JTAG pins: TCK, TMS, TDI, TDO. The only problem is that Speccy module does not expose JTAG programming pins so chip must be programmed elsewhere - using development board (available form eBay/Aliexpress), other system equiped with JTAG connector for ISP or simple self-made interface.
